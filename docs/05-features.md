
# MotoBind v2 — Feature Map

> Версия: 1.0
> Дата: октябрь 2026
> Статус: draft

## Как читать

- **P0** — без этого v2 не выйдет. Всё, что нужно для запуска закрытого пилота.
- **P1** — выйдет, но хуже. Добавляем в первую волну после запуска.
- **P2** — отложено. Не трогаем, пока P0 и P1 не закрыты.
- **Флоу** — ссылка на `docs/04-flows/...`, откуда фича вытекает.
- **Контекст** — bounded context, где живёт код.

**Принцип:** если фича не вытекает из флоу — её нет в Feature Map.

## 10. Порядок реализации (Milestones)


### Milestone 1. Фундамент (недели 1–3)

- 8.9–8.11, 8.13, 8.16–8.18 — FastAPI-скелет, async SQLAlchemy, cookies, cron, CI, Nginx, backup
- 8.1–8.4, 8.6 — Nuxt-скелет, SSR/SPA, Nitro proxy, редиректы
- 1.1–1.18 — весь Identity P0
- 7.1–7.9 — Notification P0 (нужен всем)

**Результат:** работают регистрация, логин, cookies, refresh, роли, уведомления.

### Milestone 2. Digital Garage MVP (недели 4–8)

- 2.1–2.18 — весь Garage P0
- 8.7 — PWA (базово)
- 8.5 — SEO для публичных страниц

**Результат:** можно запустить закрытый пилот на 20–50 пользователей.

### Milestone 3. Знания и SEO (недели 9–11)

- 3.1–3.12 — Knowledge P0

**Результат:** мануалы публичны, индексируются, есть SEO-трафик.

### Milestone 4. Модерация и Community (недели 12–15)

- 6.1–6.7 — Moderation P0
- 4.1–4.9 — Community P0

**Результат:** соцсеть работает, жалобы обрабатываются.

### Milestone 5. PWA и полировка (недели 16–17)

- 8.7 — PWA полностью (offline гараж, push — P2)
- 8.8 — cookie-баннер и cookie policy
- Ревизия UX после первых пользователей

**Результат:** v2 готов к публичному запуску.

### Milestone 6. B2B-пилот (недели 18–20)

- 5.1–5.9 — Marketplace P1
- По результатам пилота — решение, идём ли в полноценный B2B

**Результат:** первые мастера в системе, проверка гипотезы.

### Milestone 7. P1-волна (без срока)

- Всё остальное из P1 по контекстам
- 1.19–1.21, 2.19–2.22, 3.13–3.15, 4.10–4.12, 7.10

## 11. Что НЕ в Feature Map

Чтобы не путаться, явно выносим за скобки:

- Маркетплейс-платежи
- Сложная CRM для мастеров
- Мультигород
- Мобильное приложение (только PWA)
- Интеграции с погодой, картами, треками GPX
- Форум, чаты, личные сообщения
- Реклама и продвижение
- Партнёрская программа
- Мультиязычность
