
# Смена пароля из профиля

**Контекст:** Identity
**Триггер:** «Сменить пароль» в настройках
**Результат:** пароль обновлён, остальные сессии отозваны

## Шаги
1. User вводит текущий пароль, новый, подтверждение.
2. Backend проверяет текущий, валидирует новый.
3. Backend обновляет пароль.
4. Backend отзывает все Session, кроме текущей.
5. Frontend показывает тост «Пароль изменён».

## Что может пойти не так
- Текущий пароль неверный → 401.
- Новый пароль слабый → 422.
- Новый = текущий → 422.
- 5 попыток за 15 мин → 429.

## Эндпоинты
- `PATCH /api/v2/auth/change-password` → `{ message }`

## Решения
- Отзываем все сессии, кроме текущей — защита от угона.
- Форма уже требует текущий пароль — этого достаточно, повторная аутентификация не нужна.
