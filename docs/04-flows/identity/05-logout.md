
# Логаут

**Контекст:** Identity
**Триггер:** нажатие «Выйти»
**Результат:** cookies удалены, редирект на /login

## Шаги
1. User нажимает «Выйти».
2. Frontend шлёт POST /auth/logout с CSRF-заголовком.
3. Backend помечает Session revoked.
4. Backend удаляет cookies (Max-Age=0).
5. Frontend чистит Pinia, редиректит на /login.

## Что может пойти не так
- CSRF отсутствует → 403, но клиент всё равно чистит cookies локально.
- Сеть упала → клиент чистит cookies локально, не ждёт сервер.
- Двойной клик → второй запрос no-op.

## Эндпоинты
- `POST /api/v2/auth/logout` → `204` + Set-Cookie ×3 (Max-Age=0)

## Решения
- Логаут не должен падать. Клиент чистит локально всегда.
- Диалог подтверждения не показываем — логаут обратим.
