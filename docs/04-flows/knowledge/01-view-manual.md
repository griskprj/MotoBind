
# Просмотр мануала

**Контекст:** Knowledge
**Триггер:** переход на /manual/{id} или из каталога /manuals
**Результат:** мануал отображён, SEO-мета сформирована

## Шаги
1. Гость или User открывает /manual/{id}.
2. Backend отдаёт мануал, если status=approved. Иначе 404.
3. Nuxt рендерит страницу на сервере (SSR), мета-теги из title и description.
4. Schema.org разметка HowTo.
5. Если User авторизован — показываем кнопки «Сохранить», «Оценить» (P1).
6. Кнопка «Применить к своему мотоциклу» — если у User есть подходящий мотоцикл.

## Что может пойти не так
- Мануал не approved → 404 для гостя, 403 для чужого авторизованного.
- Автор смотрит свой rejected → видит его, с пометкой «Отклонён».

## Эндпоинты
- `GET /api/v2/manuals/{id}` → `{ manual }` — публичный, опциональный JWT
- `GET /api/v2/manuals?tab=all&page=1` → `{ manuals, pagination }`

## Решения
- Публичный доступ только к approved. Проверка на бэке, не на фронте.
- SSR для публичных страниц, ISR с revalidate 300с для каталога.
- Schema.org HowTo — обязательно.
- Гостю показываем мануал полностью. Не режем контент за авторизацию.
