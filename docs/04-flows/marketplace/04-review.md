
# Отзыв

**Контекст:** Marketplace
**Триггер:** клиент открывает завершённую заявку
**Результат:** Review создан, рейтинг мастера обновлён

## Шаги
1. Клиент открывает завершённую ServiceRequest.
2. Нажимает «Оставить отзыв».
3. Ставит оценку 1–5, опционально пишет текст.
4. Backend создаёт Review, проверяет: заявка completed, отзыва нет.
5. Рейтинг мастера пересчитывается (средний).

## Что может пойти не так
- Заявка не completed → 403.
- Отзыв уже есть → 409.
- Оценка вне 1–5 → 422.
- Мастер удалён → заявка остаётся, отзыв не создаётся.

## Эндпоинты
- `POST /api/v2/service-requests/{id}/review` → `{ review }`
- `GET /api/v2/masters/{id}/reviews` → `{ reviews, stats }`

## Решения
- Один отзыв на одну завершённую заявку.
- Отзыв можно редактировать в течение 24 часов, потом нельзя.
- Удаление отзыва — только админ.
- Рейтинг мастера — средний по всем отзывам, округление до 0.1.
- Мастер может ответить на отзыв — P1, не в v2.
