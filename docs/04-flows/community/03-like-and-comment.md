
# Лайк и комментарий

**Контекст:** Community
**Триггер:** клик по лайку или отправка комментария
**Результат:** счётчики обновлены, автор поста получил уведомление

## Шаги

### Лайк
1. User нажимает сердце на посте.
2. Backend: если лайка нет — создаёт, иначе удаляет (toggle).
3. Счётчик likes_count обновляется.
4. Автор поста получает Notification (type=social), кроме случая, когда лайкает сам себя.

### Комментарий
5. User вводит текст, нажимает «Отправить».
6. Backend создаёт Comment, comments_count++.
7. Автор поста получает Notification (type=social), кроме своего комментария.

## Что может пойти не так
- Двойной клик по лайку → идемпотентность не нужна, toggle отработает.
- Пустой комментарий → 422.
- Комментарий > 1000 символов → 422.
- Автор забанен → комментарий скрыт.

## Эндпоинты
- `POST /api/v2/posts/{id}/like` → `{ liked, likes_count }`
- `POST /api/v2/posts/{id}/comments` → `{ comment }`
- `DELETE /api/v2/comments/{id}` → `204`

## Решения
- Лайк — toggle, один эндпоинт.
- Лайк уникален на пару (user, post).
- Комментарий можно удалить: свой — всегда, чужой — только модератор.
- Уведомление автору не отправляем, если лайк/комментарий от самого себя.
- Лайки комментариев — P1, не в v2.
