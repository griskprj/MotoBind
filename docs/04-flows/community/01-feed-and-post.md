
# Лента и просмотр поста

**Контекст:** Community
**Триггер:** переход на /social или /social/post/{id}
**Результат:** лента отображена, пост открыт

## Шаги
1. User открывает /social.
2. Backend отдаёт ленту: 20 постов, свежие сверху.
3. Каждый пост: автор, аватар, контент, изображение, лайки, комментарии, timestamp.
4. Пагинация — кнопка «Показать ещё» (infinite scroll — P1).
5. Клик по посту → /social/post/{id}, полный пост + комментарии.

## Что может пойти не так
- Пустая лента → «Пока нет постов. Будьте первым».
- Пост удалён → 404.
- Автор забанен → пост скрыт из ленты (soft).

## Эндпоинты
- `GET /api/v2/posts?page=1&per_page=20` → `{ posts, pagination }`
- `GET /api/v2/posts/{id}?include_comments=true` → `{ post }`

## Решения
- Лента только для авторизованных. Гость видит CTA «Войдите, чтобы смотреть».
- Сортировка: created_at DESC. Никаких алгоритмов.
- Комментарии подгружаются вместе с постом при открытии.
- Посты забаненных не показываем вообще (не «скрыто», а не отдаём).
