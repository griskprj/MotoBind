

# Создание записи ТО в историю

**Контекст:** Garage
**Триггер:** «Добавить ТО в историю» на карточке мотоцикла
**Результат:** Maintenance создан в статусе completed

## Шаги
1. User открывает форму.
2. Выбирает мотоцикл (если их несколько).
3. Заполняет: категория (масло, тормоза, ...), название, описание.
4. Указывает дату и/или пробег выполнения
5. Backend создаёт Maintenance (status=completed).

## Что может пойти не так
- Ни пробег, ни дата не указаны → 422 «Укажите выполнение».
- completed_mileage > текущего пробега или completed_date > текущей даты → 400 «Выполненное обслуживание не может быть в будущем».
- Категория не из списка → 422.

## Эндпоинты
- `POST /api/v2/maintenances` → `{ maintenance }`

## Решения
- Обязательно: мотоцикл, категория, название, хотя бы одно из (completed_mileage, completed_date).
- Название — динамический список на бэке с возможностью установки своего названия, содержание зависит от выбранной пользователем категории.
- Категории — фиксированный список на бэке (масло, фильтры, тормоза, цепь, шины, электрика, двигатель, прочее).
