
# Удаление мотоцикла

**Контекст:** Garage
**Триггер:** «Удалить» в меню мотоцикла
**Результат:** Motorcycle и связанные данные помечены deleted (soft), из гаража исчез

## Шаги
1. User нажимает «Удалить».
2. Модалка с подтверждением: «Удалить мотоцикл и всю историю ТО?»
   Показываем счётчики: N записей ТО, M напоминаний.
3. User подтверждает.
4. Backend помечает Motorcycle.deleted_at = now.
5. Каскадно помечает Maintenance, Reminder (soft).
6. Фото удаляется физически.
7. Frontend убирает мотоцикл из списка.

## Что может пойти не так
- Есть активные ServiceRequest от мастеров → предупреждаем, но удаляем.
- Мотоцикл — единственный → гараж пустой, показываем CTA.

## Эндпоинты
- `DELETE /api/v2/motorcycles/{id}` → `204`

## Решения
- Soft delete: данные не теряем, можно восстановить через поддержку.
- Фото удаляем физически (место на диске).
- Maintenance и Reminder — soft delete каскадом.
- Счётчики в модалке — обязательны, чтобы User понимал, что теряет.
