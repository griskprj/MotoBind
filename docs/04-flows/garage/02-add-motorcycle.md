
# Добавление мотоцикла

**Контекст:** Garage
**Триггер:** «Добавить мотоцикл» из гаража
**Результат:** Motorcycle создан, показан в списке

## Шаги
1. User нажимает «Добавить мотоцикл».
2. Заполняет форму: марка, модель *, год, объём, пробег*, цвет, VIN, госномер, фото.
3. Backend валидирует, создаёт Motorcycle.
4. Если фото — отдельным запросом после создания.
5. Frontend показывает новый мотоцикл в списке.

## Что может пойти не так
- Пробег отрицательный → 422.
- Фото > 16 МБ → 413.
- Дубликат по VIN → предупреждение, но не блокируем (у одного User может быть два одинаковых мотоцикла).
- VIN невалидный → не проверяем формат, это не критично.

## Эндпоинты
- `POST /api/v2/motorcycles` → `{ motorcycle }`
- `POST /api/v2/motorcycles/{id}/photo` → `{ motorcycle }`

## Решения
- Обязательные поля: название, пробег. Остальные — опционально.
- VIN уникален только в рамках одного User, не глобально.
- Пробег при создании не может быть отрицательным.
- Мотоцикл можно создать без ТО — quick-start не обязателен.
