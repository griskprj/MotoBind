
# Редактирование мотоцикла

**Контекст:** Garage
**Триггер:** «Редактировать» на карточке мотоцикла
**Результат:** данные обновлены, гараж перерисован

## Шаги
1. User открывает форму редактирования.
2. Меняет поля (название, год, объём, цвет, VIN, госномер, заметка).
3. Отдельно: пробег — через отдельное действие «Обновить пробег».
4. Отдельно: фото — загрузить/удалить.
5. Backend сохраняет, возвращает обновлённый Motorcycle.

## Что может пойти не так
- Новый пробег меньше текущего → 422 «Пробег не может уменьшаться».
  Обходной путь: отдельная операция «Корректировка пробега» с логом (P1).
- Фото не проходит по формату → 422.
- Параллельное редактирование в двух вкладках → last-write-wins, не блокируем.

## Эндпоинты
- `PUT /api/v2/motorcycles/{id}` → `{ motorcycle }`
- `PATCH /api/v2/motorcycles/{id}/mileage` → `{ motorcycle }`
- `POST /api/v2/motorcycles/{id}/photo` → `{ motorcycle }`
- `DELETE /api/v2/motorcycles/{id}/photo` → `{ motorcycle }`
- `PATCH /api/v2/motorcycles/{id}/note` → `{ motorcycle }`

## Решения
- Пробег меняется отдельным эндпоинтом — сброс reminders.
- При обновлении пробега: `mileage_updated_at = now`, cancel активных `mileage_update` reminders.
- Заметка: max 128 символов.
- Фото: одно на мотоцикл, замена = удалить старое + загрузить новое.
